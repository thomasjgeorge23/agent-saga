## 📬 Reporting a Vulnerability

If you discover a potential security flaw in `agent-saga`, please report it directly to **Founder Thomas J George**:

- **Email**: [thomasjgeorge23@gmail.com](mailto:thomasjgeorge23@gmail.com)
- **PGP / Response Time**: Within 24 hours.

Please do **NOT** disclose vulnerabilities publicly via GitHub Issues until SAGAOPS Enterprise has confirmed and published a fix.
